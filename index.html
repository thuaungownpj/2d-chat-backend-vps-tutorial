Auto Configuration Generator

အောက်ပါအချက်အလက်များကို ဖြည့်စွက်သည်နှင့် Command များအားလုံးတွင် Auto ပြောင်းလဲသွားပါမည်။

၁ Local PC မှ Server ထဲသို့ SSH Login ဝင်ရောက်ခြင်း

  • SSH Key အမျိုးအစားပေါ်မူတည်၍ Local Terminal (Ubuntu/Mac/WSL) တွင် အောက်ပါအတိုင်း ဝင်ရောက်ပါ။
local - ssh connect
ssh -i ~/.ssh/id_ed25519 thuaung.official@192.168.1.1

၂ Package Update ပြုလုပ်ခြင်းနှင့် Docker Engine သွင်းယူခြင်း

  • Server ထဲသို့ ရောက်ရှိပါက Docker တရားဝင် Script ကို ရယူပြီး Install ပြုလုပ်ပါမည်။
bash - docker setup
sudo apt update && sudo apt install -y curl git ufw
curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh
sudo usermod -aG docker $USER

၃ GitHub Deploy Key ဖန်တီးပြီး Repo Clone လုပ်ခြင်း

  • Server ပေါ်တွင် Deploy Key ဆောက်ပြီး Public Key အား GitHub Repo > Settings > Deploy keys ထဲတွင် ထည့်သွင်းပါ။
bash - server ssh key
ssh-keygen -t ed25519 -C "vps-server" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
git clone git@github.com:tyour_gihub_ssh_linl.git

၄ Environment (.env) ပြင်ဆင်ခြင်းနှင့် Docker Container Run ခြင်း

  • Redis Host အား Docker အတွင်းရှိ `redis` Container Name သို့ အလိုအလျောက် ညွှန်းဆိုပေးပြီး Build လုပ်ပါမည်။
bash - deploy containers
cd ~/2d-chat-backend && cp .env.example .env
sed -i 's/REDIS_HOST=127.0.0.1/REDIS_HOST=redis/' .env
sudo docker compose up -d --build
sudo docker compose ps

၅ Nginx Reverse Proxy (WebSocket Support) ရေးဆွဲခြင်း

  • Nginx ကို Install ပြုလုပ်ပြီး Socket.io/WebSocket Headers အပြည့်အစုံပါဝင်သော Config ကို တိုက်ရိုက် ရေးသွင်းပါမည်။
bash - install nginx & write config
sudo apt install -y nginx certbot python3-certbot-nginx
sudo bash -c 'cat << "EOF" > /etc/nginx/sites-available/chat.yourdomain.com upstream chat_backend { server 127.0.0.1:3000; keepalive 64; } server { listen 80; server_name chat.yourdomain.com; location /socket.io/ { proxy_pass http://chat_backend; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_read_timeout 60s; proxy_send_timeout 60s; } location / { proxy_pass http://chat_backend; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; } } EOF'
sudo ln -sf /etc/nginx/sites-available/chat.yourdomain.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

၆ UFW Firewall နှင့် Free Let's Encrypt SSL (WSS/HTTPS)

  • Cloudflare တွင် Domain ကို DNS only (Grey Cloud) ထားရှိပြီးနောက် SSL ရယူပါမည်။
bash - firewall & certbot
sudo ufw allow OpenSSH && sudo ufw allow 'Nginx Full' && sudo ufw --force enable
sudo certbot --nginx -d chat.yourdomain.com
SSL ရရှိပြီးပါက Browser မှ https://chat.yourdomain.com/health သို့ သွားရောက်စစ်ဆေးနိုင်ပါသည်။
